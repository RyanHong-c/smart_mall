# SmartMall 性能与评测数据

## 一、接口性能压测（product 详情接口）

环境：Mac 本机、单实例、MySQL 8 + Redis 7 + 布隆过滤器。

| 场景 | 平均延迟 | 说明 |
|---|---|---|
| 缓存命中 | **1.84 ms**（QPS 2680） | Redis 缓存 + 布隆过滤器，2000 请求 / 100 并发 0 失败 |
| 缓存未命中 | **7.74 ms** | 走数据库 + 布隆过滤器 + Redisson 分布式锁 + 回填缓存 |
| 穿透防护 | **0.99 ms** | 布隆过滤器直接拒绝不存在的商品 ID |

**结论**：缓存命中比未命中快 **4.2 倍**；布隆过滤器把不存在的商品请求拦截在 1ms 内，防止缓存穿透打库。

复现命令：
```bash
# 预热 + 压测缓存命中
curl -o /dev/null http://127.0.0.1:8083/api/product/1
ab -n 2000 -c 100 http://127.0.0.1:8083/api/product/1
```
